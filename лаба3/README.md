# Работа 3 Процессы и потоки

C++17, Windows. Студбилет 230616, размер блока 2306160. N=10000000 итераций.

```powershell
g++ -std=c++17 -O2 -Wall -Wextra pi_win32.cpp -o pi_win32.exe
g++ -std=c++17 -O2 -Wall -Wextra -fopenmp pi_openmp.cpp -o pi_openmp.exe
.\pi_win32.exe 4
.\pi_openmp.exe 4
python benchmark.py
```

Аргумент — число потоков 1..64. Вывод CSV содержит число потоков, фактическое число, N, блок, pi и время. Вычисляется интеграл 4/(1+x²) на [0,1] методом средних прямоугольников. N — число итераций, не количество верных десятичных знаков.

Win32 создаёт весь пул через CreateThread с CREATE_SUSPENDED. Первые задания выдаются по очереди; после сигнала завершения диспетчер приостанавливает поток SuspendThread, выдаёт следующий свободный блок и вызывает ResumeThread. Поток не завершается между заданиями. Рабочий поток после расчёта только проверяет атомарные флаги и не держит пользовательских блокировок. Самоприостановка не используется: она создаёт риск потерянного пробуждения при раннем ResumeThread. Завершение кооперативное, дескрипторы закрываются. Частичные суммы складывает диспетчер после сигнала события.

OpenMP использует parallel, reduction(+:sum) и for schedule(dynamic,2306160). Динамическое изменение размера команды отключено. Число фактически запущенных потоков проверяется.

Всего блоков ceil(10000000/2306160)=5: четыре по 2306160 итераций и последний 775360. Поэтому одновременно считать могут максимум пять потоков; n=8,12,16 не даёт дополнительного вычислительного параллелизма.

benchmark.py выполняет 10 повторов каждой комбинации, порядок перемешан с фиксированным seed, проверяется pi с абсолютной погрешностью <1e-11. Таймеры охватывают создание и завершение потоков. Короткие запуски чувствительны к планировщику и фоновым процессам. Методичка не требует меню.
