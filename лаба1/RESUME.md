# Продолжение после перезагрузки

Работа сохранена 19.10.2026. Windows-приложение собрано и проверено; Linux-приложение пока не собиралось и замеры не выполнялись.

Причина сбоя WSL2: hypervisorlaunchtype Off. Установлено Auto, подтверждено в wsl-setup.txt. VirtualMachinePlatform уже Enabled, виртуализация BIOS включена. Требуется перезагрузка Windows.

После перезагрузки:
1. Проверить HypervisorPresent и `wsl --list --verbose`.
2. Завершить `wsl --install -d Ubuntu-24.04 --no-launch`, настроить доступ к дистрибутиву.
3. Установить в Ubuntu build-essential и python3.
4. Проверить C++ POSIX AIO, собрать и выполнить `bash run-linux.sh` из папки лабораторной. Проверить все correctness.txt, CSV и SVG.
5. Дополнить REPORT.md фактическими измерениями, графиками, параметрами среды и выводами. Удалить устаревшие утверждения о незавершённых проверках после их выполнения.

Скрипт выполняет серии 1, 16 и 64 МиБ, пять размеров блока, n=1,2,4,8,12,16 и три повтора; проверяет cmp и SHA-256. Синтаксис Python и Bash проверен. На данный момент handler вызывается диспетчером с SIGEV_NONE; это явно описано в README и отчёте.
